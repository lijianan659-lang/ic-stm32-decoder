ic-stm32-decoder — IC Top Marking, Cross-Ref, Package Dimensions, Date Code & STM32 Toolkit

Open-source incoming quality control (IQC) and hardware engineering library for decoding cryptic SMD package markings (210 datasheet-verified entries), IC cross-reference & EOL substitution traps (48 pairs), JEDEC vs EIAJ SMD package width traps (16 outlines), parallel ISO week / Julian / onsemi / National Semiconductor lot codes, and STM32 ordering suffixes.

CLI & Programmatic Usage (Node.js & Python 3)

git clone https://github.com/lijianan659-lang/ic-stm32-decoder.git
cd ic-stm32-decoder

# Node.js (>= 18, zero npm dependencies)
node ./bin/ic-stm32-decoder.js STM32G030F6P6TR
node ./bin/ic-stm32-decoder.js 0012

# Python 3 (>= 3.9, standard library only)
python3 -m ic_stm32_decoder STM32H743VIT6
python3 -m ic_stm32_decoder onsemi GJ
